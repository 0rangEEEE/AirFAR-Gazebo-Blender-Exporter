# Changelog

## v0.3.0

- Export Principled BSDF solid colors through separate OBJ visual groups and explicit Gazebo SDF materials.
- Include exported mesh normals, ambient light, and optional simplified collision proxies.
- Export `UAV_SPAWN` pose, world files, preview point clouds, and an Air-FAR simulator installer.
- Include an editable `maze.blend` demonstration scene and a matching `maze_gazebo_bundle.zip` with consistent map identifiers.
- Add Chinese / English setup documentation and ROS diagnostics.

## v0.2.0

- Support geometry, Gazebo mesh collision, Blender Empty spawn pose, static map preview, and Air-FAR map package generation.
